## 设计约定（长期有效）
- 背景：内嵌 base64 星空照片（离线可用，导出不污染 canvas 跨域）。
- 调色：深底极简；纯黑极简 accent `#1A1A1A`；标题暖金下划线 `#c98b24`（仅作填充，文字近白 / 白）。
- 字体：HarmonyOS Sans SC（jsdelivr CDN，含加载失败提示）；标题 / 品牌 / 英文 fallback `PingFang SC` / `Microsoft YaHei` / sans-serif。
- 头像：跨平台统一小头像，是唯一记忆锚（优先级 > 名字）；base64 内嵌，支持替换。
- 安全区：内缩 `pad = W*0.08`（8%），规避抖音 UI 遮挡（顶部作者信息、底部标题条）。真实风险是 UI 覆盖不是比例裁剪（上传只支持 3:4 / 4:3，3:4 为母比例、无裁剪）。
- 模式：`solo`（散题）/ `series`（合集）。合集时左上书名《》替换 @、显示集数徽标（纯白数字）。

## 三种比例（orientation 驱动 drawCover 按 W/H 自适应）
- 竖 3:4（默认封面，抖音主页网格）
- 横 4:3
- 微信 2.35:1（公众号首图）：走专属 `drawWxCover` 分支（`drawCover` 第 6 参数 `layout="wx"`，顶部提前 `return`），去掉顶部栏目，两段式 = 标题区（上）+ 底部栏（下：左 头像 + 王同学胡说 / 右 slogan）。底部头像直径 `H*0.14`、品牌名与 slogan 同字号 `H*0.06`、间距 `H*0.027`（均为 2026-10-19 末次缩至 2/3 后的数值）。
- 方形 1:1（视频号合集封面）：导出固定 **744×744**（不随 scaleSel 变）。**复用 `drawCover`**，与竖/横封面完全一致、跟随 `state.mode`（散题/合集）——散题显示 @+品牌名、合集显示《书名》+ 集数徽标；**不单独加书封图**（2026-11-01 应要求去除书封大图，改回与 3:4/4:3 同版式）。`download("s")` 固定 744。
- ⚠️ **安全区约束（关键）**：平台上传 744 后会裁掉中心 **592×592** 以外，故方形必须让所有内容落在中心 592 内。`drawCover` 对方形传入 `safeInset = round(W*(744-592)/(2*744))`（744 下 =76px），背景/蒙版铺满整张 744，内容整体平移进中心 592 设计框（再留 8% 内边距）。预览方形图叠加虚线「592 安全区」参考框（仅预览，导出不含）。
